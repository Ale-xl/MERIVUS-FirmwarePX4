# 连续执行器效能估计

定义 `lambda_i` 为第 i 个动力通道相对健康基线的效能，范围 `[0, 1]`。初版使用有界、低计算量的自适应响应模型；只有解锁、离地、推力超过门限且电机输入具有足够差分激励时才更新。

估计器必须具备：

- 数值 bounds 与每秒变化率限制。
- 输入与角加速度低通。
- excitation/confidence 门控。
- 基线建立阶段和 `model_valid` 状态。
- 异常持久时间，避免单样本触发 degraded/failed。

该估计不是 ESC 遥测替代品。未来可融合 RPM、电流、电压和温度，但缺少这些 topic 时不强制改驱动。

当前通过 `EffectivenessEstimator` 抽象使用共享协方差的递归最小二乘模型，从 motor command 预测三轴角加速度。每个电机的三轴系数范数在健康激励阶段被冻结为 nominal，在线范数与 nominal 的比值形成独立、有下界和变化率限制的 effectiveness。遗忘因子可配置。12 电机最坏情况下每次更新为 O(12²)；模块以 50 Hz 运行，不使用 FFT、神经网络或动态内存分配的高频路径。

合成四旋翼响应冒烟测试中，健康基线建立后将第 2 路真实响应缩放到 50%，估计结果约为 `[1.000, 0.702, 1.000, 0.968]`，第 2 路 confidence 为 1.0。该结果只证明数值路径和连续响应方向正确，不等价于 SITL、真实气动或实机识别精度。
