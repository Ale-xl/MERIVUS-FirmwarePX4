# 连续执行器效能估计

定义 `lambda_i` 为第 i 个动力通道相对健康基线的效能，范围 `[0, 1]`。初版使用有界、低计算量的自适应响应模型；只有解锁、离地、推力超过门限且电机输入具有足够差分激励时才更新。

估计器必须具备：

- 数值 bounds 与每秒变化率限制。
- 输入与角加速度低通。
- excitation/confidence 门控。
- 基线建立阶段和 `model_valid` 状态。
- 异常持久时间，避免单样本触发 degraded/failed。

该估计不是 ESC 遥测替代品。未来可融合 RPM、电流、电压和温度，但缺少这些 topic 时不强制改驱动。
