## 物理含义与未解决项

`FTC_SIM_EFF` 当前缩放 HIL 仿真输出命令。锁定 Iris 模型的目标转速为 `100 + 1000 * signal`，基本推力与转速平方成正比，另有动态和气动修正。因此 EFF70 并不直接等于物理 λ=0.70。

当前 λ 统一作用于 B 的整列；Gazebo 的推力还乘速度相关修正，而偏航反扭矩采用不同计算路径。强机动回归误差可能包含这些模型项、陀螺耦合、基线增益及时间误差，贡献尚未分离。SITL 合成 ESC RPM 也不能当作独立物理真值。
