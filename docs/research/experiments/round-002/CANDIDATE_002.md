# 候选 002：带限残差与水平速度反馈耦合

状态：`HYPOTHESIS_UNVERIFIED`。该结构由首轮失败日志提出，不声称新的控制定理或性能改进。代码由 [candidate.json](../../../../Tools/merivus/flight_control_research/candidate.json) 生成，只有 SITL 的 `active` 模式可将其加到 PX4 原速度环加速度设定点上。

令 `e_v` 为 PX4 速度环误差，`r = a_measured - u_previous` 为现有残差代理，`L_τ` 为一阶低通。水平补偿为

```text
Δa_xy = sat_0.35(0.15 e_v,xy − 0.15 [L_0.12(r_xy) − L_1.5(r_xy)])
Δa_z  = 0
u     = u_PX4 + Δa
```

两个低通之差使恒定残差的补偿趋近零，以抑制首轮在正常悬停时出现的持续修正；较快分量尝试抵消阵风开始与停止时的瞬态，速度反馈提供小幅附加阻尼。每轴修正受生成图的限幅和全局 0.5 m/s² 上限约束；输入或周期失效时复用 PX4 原输出。

这个残差不是外扰的直接测量，含有估计噪声、延迟与执行器动态。低通相位和额外速度反馈也可能放大超调。先在 `shadow` 检查数值与限幅，再按 [预注册协议](PROTOCOL.md)运行发现集和保留集；若任一门槛失败，记录失败并淘汰。
